# デフォルトスキン(def)デザイン方針

KonaWiki3 のデフォルトスキン `def` のデザイン方針をまとめたドキュメントです。
`def` スキンのスタイルを変更するときは、この方針に従ってください。

- 関連 Issue: [#288 デフォルトスキンのブラッシュアップ](https://github.com/kujirahand/konawiki3/issues/288)
- スキンの仕組み全般: [skin.md](skin.md)

---

## 1. コンセプト

**ビジネスライクで堅実、余白が美しく見えるデザイン**

- 社内 Wiki・マニュアル・議事録など、業務文書を長時間読んでも疲れないこと。
- 装飾は最小限にし、文書の構造(見出し・段落・表)が一目で分かること。
- 色ではなく **余白と文字の太さ・大きさ** で情報の階層を表現すること。

### やらないこと

- グラデーション、影(`box-shadow`)、テキストシャドウなどの装飾的な表現。
- 見出しの背景色のベタ塗り。
- 外部 Web フォントの読み込み(表示速度と、オフライン環境・静的出力での動作を優先)。
- HTML テンプレートの変更(CSS だけで対応します)。

---

## 2. 変更範囲とファイル構成

### CSS の読み込み順

```text
1. kona3engine/resource/pure-min.css            # Pure.css (リセット・グリッド)
2. kona3engine/resource/grids-responsive-min.css
3. kona3engine/resource/kona3def.css            # 全スキン共通の基本スタイル
4. kona3engine/resource/darkmode.css            # 全スキン共通のダークモード
5. skin/def/kona3.css                           # def スキン固有のスタイル ← ここに書く
6. drawer.css                                   # ドロワーメニュー
```

### 方針

- **デザインの変更は `skin/def/kona3.css` に書きます。**
- `kona3engine/resource/kona3def.css` は aqua・nako3・single など **全スキンの土台** です。各スキンは一部だけを上書きし、残りは `kona3def.css` に頼っています。そのため、`def` の見た目を変える目的で `kona3def.css` を編集してはいけません。全スキンに共通するバグ修正だけを `kona3def.css` で行います。
- `darkmode.css` には手を入れず、`def` 固有のダーク配色は `skin/def/kona3.css` の中で定義します(「5. ダークモード」を参照)。

## 3. デザイントークン(CSS 変数)

色・余白・幅は `skin/def/kona3.css` 冒頭の `:root` に CSS 変数として定義し、個々のルールでは変数だけを参照します。直接の色コードや `px` の固定値を、ルールの中に散らばらせないようにします。

変数名は他スキンや将来の共通化と衝突しないよう、`--k3-` で始めます。

### 色

白地に紺〜スレートグレーの文字、アクセントは青1色に絞ります。

| 変数 | 用途 | ライト(初期値) | ダーク(初期値) |
|------|------|----------------|----------------|
| `--k3-color-text` | 本文の文字 | `#1f2933` | `#e4e7eb` |
| `--k3-color-text-muted` | 日付・補足・キャプション | `#616e7c` | `#9aa5b1` |
| `--k3-color-heading` | 見出しの文字 | `#102a43` | `#f0f4f8` |
| `--k3-color-bg` | ページ背景 | `#ffffff` | `#15191e` |
| `--k3-color-bg-subtle` | 表のヘッダー行・コード・引用の背景 | `#f5f7fa` | `#1f252c` |
| `--k3-color-border` | 罫線・区切り線 | `#e4e7eb` | `#323a44` |
| `--k3-color-border-strong` | h1・h2 の下線など強めの罫線 | `#cbd2d9` | `#52606d` |
| `--k3-color-accent` | リンク・見出しのアクセント線 | `#1f5fbf` | `#7cb4ff` |
| `--k3-color-accent-hover` | リンクのホバー | `#174a96` | `#a8ccff` |

- 初期値は目安です。実装時に調整してかまいませんが、本文の文字と背景のコントラスト比は **4.5:1 以上**(WCAG AA)を保ちます。
- 色の役割を増やすときは、新しい変数を追加してから使います。

### 余白

余白は次の段階だけを使い、中途半端な値を作らないようにします。単位は `em` を基本にします(利用者が文字サイズを変更する機能に追従させるため)。

| 変数 | 値 | 主な用途 |
|------|----|---------|
| `--k3-space-1` | `0.25em` | アイコンと文字の間など |
| `--k3-space-2` | `0.5em` | セル内の上下余白、リスト項目の間 |
| `--k3-space-3` | `1em` | 段落の間、セル内の左右余白 |
| `--k3-space-4` | `1.5em` | ブロック要素(表・コード・引用)の上下 |
| `--k3-space-5` | `2em` | h3 以下の見出しの上 |
| `--k3-space-6` | `3em` | h1・h2 の見出しの上、セクションの区切り |

### 幅

| 変数 | 値 | 用途 |
|------|----|------|
| `--k3-width-content` | `48rem`(768px 相当) | 本文カラムの最大幅 |
| `--k3-radius` | `4px` | コード・ボタンの角丸(これ以上丸くしない) |

## 4. 要素ごとの方針

### タイポグラフィ

- フォントは OS 標準の日本語フォントスタックを使います。

  ```css
  font-family: system-ui, -apple-system, "Segoe UI", "Hiragino Sans",
    "Hiragino Kaku Gothic ProN", "Noto Sans JP", Meiryo, sans-serif;
  ```

- コードは等幅フォント(`ui-monospace, Menlo, Consolas, monospace`)を使います。
- 本文の行間は `1.75` 前後にします。単位なしの値で指定します。
- 文字サイズは `em` / `rem` で指定します。利用者設定の文字サイズ・行間(`localStorage` の `kona3_font_size` / `kona3_line_height`)が `#kona3_layout_show` に `!important` で適用されるため、子要素は相対値で書いて追従させます。

### 見出し

背景色のベタ塗りはやめ、文字サイズ・太さ・罫線・上の余白で階層を表します。

| 見出し | 表現 |
|--------|------|
| h1 | 大きめの文字、太字、下に `--k3-color-border-strong` の罫線 |
| h2 | 左に `--k3-color-accent` の細い縦線(3px 程度)、背景なし |
| h3 | 太字、下に `--k3-color-border` の細い罫線 |
| h4〜h6 | 太字のみ。罫線なし |

- 見出しの **上の余白は下の余白より大きく** 取り、見出しが直後の本文に属して見えるようにします。

### リンク

- 色は `--k3-color-accent` のみ。訪問済みリンクの色は大きく変えません。
- ホバー時は下線を表示します。背景色の変化や `padding` の増減など、レイアウトが動く表現は使いません。

### 表

- ヘッダー行は `--k3-color-bg-subtle` の背景と太字で区別します。
- 罫線は横線を基本にし、`--k3-color-border` を使います。
- セルの余白は上下 `--k3-space-2`、左右 `--k3-space-3` にします。
- 横幅が足りない画面では、表だけを横スクロールさせ、ページ全体がはみ出さないようにします。

### コード・引用

- `pre` / `code` / `.code`: `--k3-color-bg-subtle` の背景、`--k3-color-border` の罫線、`--k3-radius` の角丸。
- 引用: 左に罫線、文字色は `--k3-color-text-muted`。

### ヘッダー・メニュー・フッター

- ヘッダー(`#kona3_layout_header`)は白地と下罫線だけの構成にします。
- サイドメニュー(`#kona3_menubar`)は本文と区切り線1本で分け、項目間の余白を揃えます。
- フッター(`#wikifooter`)・ログインバーは、本文より目立たない配色にします。

### フォーム・ボタン

- Pure.css のボタン(`.pure-button`)と調和させ、角丸は `--k3-radius`、主ボタンのみ `--k3-color-accent` を使います。

## 5. ダークモード

ダークモードは、利用者がメニューの切替を選ぶと `<body>` に `dark-theme` クラスが付く仕組みです(設定は `localStorage` の `kona3_theme` に保存されます)。

`def` スキンでは **変数の値だけを切り替えます**。

```css
:root {
  --k3-color-text: #1f2933;
  --k3-color-bg: #ffffff;
  /* ... */
}

body.dark-theme {
  --k3-color-text: #e4e7eb;
  --k3-color-bg: #15191e;
  /* ... */
}
```

- 個々のセレクタに `body.dark-theme` 用のルールを書き足すのではなく、変数の再定義で対応します。こうすると、新しく追加したプロパティもダーク時に自動で追従します。
- ただし `darkmode.css` には `body.dark-theme #kona3_main h2` のような、詳細度の高い固定色のルールがあります。これらは `skin/def/kona3.css` の `#kona3_main h2` より優先されるため、変数を切り替えるだけでは効きません。`darkmode.css` が色を指定している要素には、同じ詳細度のセレクタ(`body.dark-theme ...`)で変数を参照するルールを `skin/def/kona3.css` に書き、上書きします。

---

## 6. レスポンシブ・印刷

- ブレークポイントは既存に合わせ、`48em`(PC 幅)と `480px`(スマホ幅)を使います。
- スマホ幅では左右の余白を `--k3-space-3` 程度に詰め、本文の幅を確保します。
- 印刷時(`@media print`)は背景色を使わず、罫線と文字だけで構造が分かるようにします。印刷モードではダークモードが適用されません。

## 7. 確認項目

`def` スキンを変更したら、次の項目を確認します。

- [ ] 通常ページ(Konawiki 記法 / Markdown)、編集、検索、添付、ログイン、設定、ユーザー一覧
- [ ] 上記の PC 幅・スマホ幅・ダークモード
- [ ] 主なプラグインの出力(コメント、タグ、filecode、目次など)
- [ ] 印刷プレビュー
- [ ] 静的出力(`just build`)したページ
- [ ] スキンを aqua・nako3・single に切り替えても見た目が変わっていないこと
- [ ] `just test` が全件パスすること
