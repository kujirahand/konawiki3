# デフォルトスキン(def)デザイン方針

KonaWiki3 のデフォルトスキン `def` のデザイン方針をまとめたドキュメントです。
`def` スキンのスタイルを変更するときは、この方針に従ってください。

- 関連 Issue: [#288 デフォルトスキンのブラッシュアップ](https://github.com/kujirahand/konawiki3/issues/288)
- スキンの仕組み全般: [skin.md](skin.md)

---

## 1. コンセプト

**ビジネスライクで堅実、余白が美しく見えるデザイン**

- 社内 Wiki・マニュアル・議事録など、業務文書を長時間読んでも疲れないこと。
- 装飾は最小限にし、文書の構造(見出し・段落・表)が一目で分かること。
- 色ではなく **余白と文字の太さ・大きさ** で情報の階層を表現すること。

### やらないこと

- グラデーション、影(`box-shadow`)、テキストシャドウなどの装飾的な表現。
- 見出しの背景色のベタ塗り。
- 外部 Web フォントの読み込み(表示速度と、オフライン環境・静的出力での動作を優先)。
- HTML テンプレートの変更(CSS だけで対応します)。

## 2. 変更範囲とファイル構成

### CSS の読み込み順

```text
1. kona3engine/resource/pure-min.css            # Pure.css (リセット・グリッド)
2. kona3engine/resource/grids-responsive-min.css
3. kona3engine/resource/kona3def.css            # 全スキン共通の基本スタイル
4. kona3engine/resource/darkmode.css            # 全スキン共通のダークモード
5. skin/def/kona3.css                           # def のスタイル ← ここに書く(全スキンの土台)
6. skin/{スキン名}/kona3.css                    # 派生スキンのスタイル(def 以外のとき)
7. drawer.css                                   # ドロワーメニュー
```

### 方針

- **デザインの変更は `skin/def/kona3.css` に書きます。**
- `skin/def/kona3.css` は、aqua・nako3・single など **派生スキンの土台** でもあります。派生スキンは `def` の変数(`--k3-*`)を上書きし、そのスキン固有の装飾だけを足しています。そのため、`def` の変更は派生スキンにも反映されます。`def` を変えたら、派生スキンの表示も確認してください。
- `kona3engine/resource/kona3def.css` は全スキン共通の、さらに下の土台です。`def` の見た目を変える目的で `kona3def.css` を編集してはいけません。全スキンに共通するバグ修正だけを `kona3def.css` で行います。
- Issue #340 以降、`kona3def.css` と `drawer.css` も `--k3-*` トークンをフォールバック付きで参照する。印刷用スタイル・filecode の構文パレットなど、固定色が妥当な箇所はリテラルのまま残す。
- 派生スキンへの注意: `info` / `success` / `warn` / `danger` の状態トークンは意味色として全スキン共通を基本とするが、`--k3-color-accent-subtle` はスキンのアクセントに連動する色なので、派生スキンでも `:root` と `body.dark-theme` の両方で上書きすること(aqua / nako3 / single は対応済み)。なお `kona3def.css` のレイアウト幅も `--k3-width-layout` に統一したため、トークンを持たない独自スキンでは従来の 768px ではなくフォールバックの 64rem が効く。
- `darkmode.css` には手を入れず、`def` 固有のダーク配色は `skin/def/kona3.css` の中で定義します(「5. ダークモード」を参照)。

## 3. デザイントークン(CSS 変数)

色・余白・幅は `skin/def/kona3.css` 冒頭の `:root` に CSS 変数として定義し、個々のルールでは変数だけを参照します。直接の色コードや `px` の固定値を、ルールの中に散らばらせないようにします。

変数名は他スキンや将来の共通化と衝突しないよう、`--k3-` で始めます。

### 色

白地に紺〜スレートグレーの文字、アクセントは青1色に絞ります。

| 変数 | 用途 | ライト(初期値) | ダーク(初期値) |
|------|------|----------------|----------------|
| `--k3-color-text` | 本文の文字 | `#1f2933` | `#e4e7eb` |
| `--k3-color-text-muted` | 日付・補足・キャプション | `#616e7c` | `#9aa5b1` |
| `--k3-color-heading` | 見出しの文字 | `#102a43` | `#f0f4f8` |
| `--k3-color-bg` | ページ背景 | `#ffffff` | `#15191e` |

- 色の役割を増やすときは、新しい変数を追加してから使います。
- `--k3-color-summary` は白背景に対するコントラスト比が約2.5:1しかないため、文字色には使わず、線やアイコン等の装飾専用とします。

### 余白

余白は次の段階だけを使い、中途半端な値を作らないようにします。単位は `em` を基本にします(利用者が文字サイズを変更する機能に追従させるため)。

| 変数 | 値 | 主な用途 |
|------|----|---------|
| `--k3-space-1` | `0.25em` | アイコンと文字の間など |
| `--k3-space-2` | `0.5em` | セル内の上下余白、リスト項目の間 |
| `--k3-space-3` | `1em` | 段落の間、セル内の左右余白 |
| `--k3-space-4` | `1.5em` | ブロック要素(表・コード・引用)の上下 |
| `--k3-space-5` | `2em` | 見出しの上、水平線の上下 |
| `--k3-space-6` | `3em` | 本文の末尾など、大きな区切り |

`em` は指定した要素の文字サイズが基準になります。そのため、見出しの上に同じ `--k3-space-5` を使っても、文字の大きい h1・h2 ほど余白が広くなり、自然に階層が付きます。

### 幅

| 変数 | 値 | 用途 |
|------|----|------|
| `--k3-width-layout` | `64rem`(1024px 相当) | ヘッダー・本文・フッターの最大幅。PC 幅では本文が約 19/24、メニューが約 5/24 を使い、段落は `--k3-measure` により 1 行 40 字前後までになります |
| `--k3-measure` | `40em` | 本文の最大行長。`.contents` 直下の段落系要素(p / ul / ol / dl / blockquote / .resmark)だけに `max-width` として適用します。見出し・表・コード・画像・プラグイン出力はカラム幅いっぱいを使います。`none` で無効化できます(印刷時は `none`。派生スキンで無効にしたいときも `:root { --k3-measure: none; }`) |
| `--k3-radius` | `4px` | コード・ボタンの角丸(これ以上丸くしない) |

### 文字・行間

値は単位なしの数値か `em` で、利用者の文字サイズ設定に追従します。色ではないため、ダークモードでの再定義は不要です。

| 変数 | 値 | 用途 |
|------|----|------|
| `--k3-line-height-body` | `1.85` | 本文の行間(`#kona3_layout_show` にだけ指定) |
| `--k3-line-height-tight` | `1.35` | 見出し・表の行間 |
| `--k3-line-height-code` | `1.6` | コード(`pre`)の行間 |
| `--k3-fs-h1` | `1.75em` | h1 の文字サイズ |
| `--k3-fs-h2` | `1.45em` | h2 の文字サイズ |
| `--k3-fs-h3` | `1.2em` | h3 の文字サイズ |
| `--k3-fs-h4` | `1.05em` | h4 の文字サイズ |
| `--k3-fs-small` | `0.875em` | 日付・メモ・画像キャプションなど小さい文字(下限) |
| `--k3-fs-code` | `0.9em` | コード(`pre` / `span.code`)の文字サイズ |

## 4. 要素ごとの方針

### タイポグラフィ

- フォントは OS 標準の日本語フォントスタックを使います。

  ```css
  font-family: system-ui, -apple-system, "Segoe UI", "Hiragino Sans",
    "Hiragino Kaku Gothic ProN", "Noto Sans JP", Meiryo, sans-serif;
  ```

- コードは等幅フォント(`ui-monospace, Menlo, Consolas, monospace`)を使います。
- 本文の行間は `--k3-line-height-body`(`1.85`)です。単位なしの値で指定します。`#kona3_layout_show` にだけ指定し、子孫には書きません(利用者設定の継承を切らないため。例外は見出し・表・コード)。
- 和文組版として、本文に `line-break: strict`(行頭禁則を厳格に)と `text-autospace: normal`(和欧間の空き)を指定します。等幅テキスト(`pre` / `code` など)と入力欄は桁揃えのため `text-autospace: no-autospace` に戻します。見出しには `word-break: auto-phrase`(文節で改行)と `text-spacing-trim: trim-start`(行頭の全角括弧を詰める)を指定します。いずれも漸進的強化で、未対応ブラウザでは無視されます。
- 文字サイズは `em` / `rem` で指定します。利用者設定の文字サイズ・行間(`localStorage` の `kona3_font_size` / `kona3_line_height`)が `#kona3_layout_show` に `!important` で適用されるため、子要素は相対値で書いて追従させます。

### 見出し

背景色のベタ塗りはやめ、文字サイズ・太さ・罫線・上の余白で階層を表します。

| 見出し | サイズ | 表現 |
|--------|--------|------|
| h1 | `--k3-fs-h1`(1.75em) | 大きめの文字、太字、下に `--k3-color-border-strong` の罫線 |
| h2 | `--k3-fs-h2`(1.45em) | 左に `--k3-color-accent` の細い縦線(3px 程度)、背景なし |
| h3 | `--k3-fs-h3`(1.2em) | 太字、下に `--k3-color-border` の細い罫線 |
| h4 | `--k3-fs-h4`(1.05em) | 太字のみ。罫線なし |
| h5・h6 | `1em` | 太字のみ。罫線なし |

- 見出しの **上の余白は下の余白より大きく** 取り、見出しが直後の本文に属して見えるようにします。
- 上の余白は h1・h2 が `--k3-space-6`、h3 以下が `--k3-space-5` です(余白は見出し自身の em で解決されるため、上位の見出しほど広くなります)。本文の先頭の h1〜h3 は上の余白を 0 にします。
- 見出しの行間は `--k3-line-height-tight` です。

### リンク

- 色は `--k3-color-accent` のみ。訪問済みリンクの色は大きく変えません。
- 本文(`.contents`)中のリンクは、色だけに頼らずリンクと分かるよう、常に細い下線(1px、`text-underline-offset: 0.2em`)を付け、ホバーで 2px にします。見出しアンカー(`a.anchor_super`)とボタン(`a.pure-button`)には下線を付けません。本文外(ログインバー・タグ行など)は従来どおり、ホバー時だけ下線を表示します。
- 背景色の変化や `padding` の増減など、レイアウトが動く表現は使いません。

### 表

- ヘッダー行は `--k3-color-bg-subtle` の背景と太字で区別します。
- 罫線は横線を基本にし、`--k3-color-border` を使います。
- セルの余白は上下 `--k3-space-2`、左右 `--k3-space-3` にします。
- 横幅が足りない画面では、表だけを横スクロールさせ、ページ全体がはみ出さないようにします。
- 数字の幅を揃えるため `font-variant-numeric: tabular-nums` を指定します。行間は `--k3-line-height-tight` で、表の中には利用者の行間設定は効きません(密度を優先)。

### コード・引用

- `pre` / `code` / `.code`: `--k3-color-bg-subtle` の背景、`--k3-color-border` の罫線、`--k3-radius` の角丸。
- コードの文字サイズは `--k3-fs-code`、行間は `--k3-line-height-code` です。
- 引用: 左に罫線、文字色は `--k3-color-text-muted`。和文に斜体は使わないため `font-style: normal` にします。

### ヘッダー・メニュー・フッター

- ヘッダー(`#kona3_layout_header`)は白地と下罫線だけの構成にします。
- サイドメニュー(`#kona3_menubar`)は本文と区切り線1本で分け、項目間の余白を揃えます。
- フッター(`#wikifooter`)・ログインバーは、本文より目立たない配色にします。

### フォーム・ボタン

- Pure.css のボタン(`.pure-button`)と調和させ、角丸は `--k3-radius`、主ボタンのみ `--k3-color-accent` を使います。

## 5. ダークモード

ダークモードは、利用者がメニューの切替を選ぶと `<body>` に `dark-theme` クラスが付く仕組みです(設定は `localStorage` の `kona3_theme` に保存されます)。

`def` スキンでは **変数の値だけを切り替えます**。

```css
:root {
  --k3-color-text: #1f2933;
  --k3-color-bg: #ffffff;
  /* ... */
}

body.dark-theme {
  --k3-color-text: #e4e7eb;
  --k3-color-bg: #15191e;
  /* ... */
}
```

- 個々のセレクタに `body.dark-theme` 用のルールを書き足すのではなく、変数の再定義で対応します。こうすると、新しく追加したプロパティもダーク時に自動で追従します。
- `darkmode.css`(全スキン共通のダークモード)も、配色を CSS 変数(`--k3d-*`)で定義しています(#294)。`--k3d-*` の多くは `def` の `--k3-*` トークンを参照しているため、`--k3-*` を切り替えるだけで `darkmode.css` 側の見出し・表・フォームなども追従します。`def` のデザインに合わないもの(見出しに背景を付けない、など)だけ、変数ブロックの中で `--k3d-*` を再定義します。

```css
body.dark-theme {
  --k3-color-text: #e4e7eb;
  /* ... */
  --k3d-h1-bg: transparent;
  --k3d-h2-bar: 3px solid var(--k3-color-accent);
}
```

- 例外は見出しのアンカー(`a.anchor_super`)だけです。`darkmode.css` の汎用リンク色(`body.dark-theme #kona3_main a:link`)より詳細度が低いため、`body.dark-theme` から始まるセレクタで詳細度を上げて指定します。`!important` は不要です。
- ダーク用の上書きに `!important` を付けていないことは、テスト(`kona3engine/tests/skin_def.test.php`)で確認しています。

## 6. レスポンシブ・印刷

- ブレークポイントは既存に合わせ、`48em`(PC 幅)と `480px`(スマホ幅)を使います。
- スマホ幅では左右の余白を `--k3-space-3` 程度に詰め、本文の幅を確保します。
- 列の多い表は、セルに最小幅(`5em`)を取り、収まらない分は表だけを横スクロールさせます。
- 印刷時(`@media print`)は背景色を使わず、罫線と文字だけで構造が分かるようにします。横スクロールは紙では見えないため、表は全列を印刷します。
- 印刷時の組版:
  - `@page` の余白は `20mm`、本文は `10.5pt` です(`body` に指定するため、利用者の文字サイズ設定はこの値に対する倍率として効きます)。
  - 紙は行長が用紙で決まるため、印刷時は `--k3-measure: none` で行長の制限を外します。
  - `#kona3_main` に `orphans: 3` / `widows: 3` を指定します。見出しの直後では改ページしません(`break-after: avoid`)。
  - 表は全体ではなく行(`tr`)単位で分割を避け(長い表で大きな空白を作らない)、`thead` を各ページに繰り返します。
  - `pre` は `break-inside: avoid` で短いものを1ページにまとめ、`overflow: visible` + `white-space: pre-wrap` で長い行を折り返します。1ページを超える長いコードは分割されます。
- 印刷モード(`?print`)ではダークモードが適用されません。ダークモードのままブラウザから印刷した場合もライトの配色で出力されるよう、ダーク用の変数の再定義は `@media screen` の中に置きます。`darkmode.css` も全体が `@media screen` 限定のため、印刷時にダークの配色が残ることはありません。

## 7. 確認項目

`def` スキンを変更したら、次の項目を確認します。

- [ ] 通常ページ(Konawiki 記法 / Markdown)、編集、検索、添付、ログイン、設定、ユーザー一覧
- [ ] 上記の PC 幅・スマホ幅・ダークモード
- [ ] 主なプラグインの出力(コメント、タグ、filecode、目次など)
- [ ] 印刷プレビュー
- [ ] 静的出力(`just build`)したページ
- [ ] スキンを aqua・nako3・single に切り替えても崩れないこと(ライト・ダーク)
- [ ] single スキンで本文の段落が 40em、表は全幅になること
- [ ] 利用者設定の行間を変えたとき、本文に効き、表には効かないこと
- [ ] 印刷プレビューで長いコード・長い表が欠けないこと
- [ ] `just test` が全件パスすること
