# KonaWiki3 AI執筆支援機能

KonaWiki3の編集画面では、AIを使って文章の校正、言い換え、続きの作文、品質チェック、改善提案を行えます。
AIは自動的に本文を書き換えるのではなく、ユーザーが明示的にボタンやショートカットキーを実行したときだけ動作します。
プロンプト（AIへの指示文）はサーバー側で組み立てるため、画面には表示されません。

## 利用できる機能

編集画面の「AI支援」ボタンでAIパネルを開くと、次の機能ボタンが並びます。ボタンを押すとすぐに実行されます。

| ボタン | 対象 | 結果 |
|---|---|---|
| 文書校正 | 本文全体 | 誤字脱字・表記ゆれなどの修正候補の一覧 |
| 言い換え | 選択範囲 | 言い換え候補（最大3件） |
| 続きを追加 | 選択範囲の直後（選択がなければカーソル位置の直前までの文章） | 続きの文章 |
| 品質チェック | 本文全体 | 100点満点の点数、総評、良い点、改善が必要な点 |
| 改善提案 | 本文全体 | 改善点の一覧（置換案があるものは置換できます） |

ナビの「AIチェック」は、AIパネルを開くと同時に文書校正を実行します。

## 初期設定

管理者でログインし、設定画面の「AI」セクションを設定します。
編集画面のAIパネルにある「AI設定を編集」リンクから、設定画面のAIセクションを新しいウィンドウで開けます。

主な設定項目は次の通りです。

- AI Provider: `OpenAI` または `OpenRouter` を選びます。
- OpenAI API Key: OpenAIを使う場合に指定します。
- OpenAI API Model: OpenAIで使うモデルを選びます。
- OpenRouter API Key: OpenRouterを使う場合に指定します。
- OpenRouter Model: OpenRouterで使うモデル名を指定します。
- OpenAI Basic Instruction: AIに渡す基本指示です。
- ショートカットキー > 文章補完: 既定値は `Ctrl+Shift+H` です。
- ショートカットキー > 誤字脱字修正: 既定値は `Ctrl+Shift+J` です。
- ショートカットキー > USER_PROMPT1: 既定値は `Ctrl+Alt+1` です。
- ショートカットキー > USER_PROMPT2: 既定値は `Ctrl+Alt+2` です。

APIキー欄には実際のキーを入力できます。
環境変数を使う場合は、`@ENV:OPENAI_API_KEY` や `@ENV:OPENROUTER_API_KEY` のように指定します。

OpenAIを使う場合、モデル名は設定画面の選択肢から選びます。
OpenRouterを使う場合、利用したいモデル名を `openrouter_model` に直接入力します。
編集画面にはモデル入力欄を表示しません。モデルの変更は設定画面で行います。

## 編集画面での使い方

### 文書校正

1. 「AI支援」を押してAIパネルを開き、「文書校正」を押します（「AIチェック」でも同じです）。
2. 修正候補が一覧で表示されます。
3. 候補ごとに次の操作ができます。
   - 置換: 本文中の該当箇所を修正候補で置き換えます。
   - 探す: 本文中の該当箇所を選択します。
   - Copy: 修正候補をコピーします。
   - 取消: その候補を結果欄から消します。
4. 候補が2件以上あるときは、結果の見出しに「全部適用」ボタンが表示されます。
   残っている候補をまとめて置換し、「N件適用 / M件見つかりません」と表示します。
   本文に見つからなかった候補は結果欄に残るので、「探す」で確認できます。

### 言い換え

1. 本文中の言い換えたい範囲を選択します（選択がないと、案内が表示されるだけで実行されません）。
2. 必要なら「言い換え方」の入力欄に指示を入力します（例: もっと丁寧に）。空欄のときは既定の指示が使われます。
   入力欄をクリックすると候補が出ます。入力した内容はブラウザに保存されます。
3. 「言い換え」を押すと、候補が表示されます。候補の「置換」で選択範囲が置き換わります。

### 続きを追加

選択範囲の直後（選択がなければカーソル位置）に続く文章を生成します。
結果欄の「挿入」を押すと、その位置に挿入します。

### 品質チェック・改善提案

品質チェックは点数（0〜100）と、総評、良い点、改善が必要な点を表示します。
改善提案は改善点を一覧表示し、置換案がある提案には「置換」「探す」ボタンが付きます。

### AI変更を元に戻す

AIによる本文の変更（置換・全部適用・挿入）は、パネルの「AI変更を元に戻す」ボタンで直前の状態に戻せます。
ブラウザの Ctrl+Z の履歴は、プログラムによる本文変更で失われるため、AIの変更はこのボタンで戻してください。

## ショートカットキー

設定画面のAIセクションでショートカットキーを変更できます。
既定値は次の通りです。

- `Ctrl+Shift+H`: 続きを生成し、結果欄を経由せず、選択範囲の直後（選択がなければカーソル位置）へ直接挿入します。
- `Ctrl+Shift+J`: 文書校正を実行します。
- `Ctrl+Alt+1`: ユーザーひな形 `# USER_PROMPT1` を実行します。
- `Ctrl+Alt+2`: ユーザーひな形 `# USER_PROMPT2` を実行します。

ショートカットキーは設定で変更できますが、ブラウザやOSが予約しているキーはページ側で捕捉できない場合があります。
例えば `Ctrl+N` や `Ctrl+J` は多くのブラウザで新規ウィンドウやダウンロード表示に割り当てられています。

## ユーザーひな形

標準の5機能以外に、自分専用のプロンプトを `data/ai_prompt.md` に書いて使えます。
AIパネルの「ひな形を編集」リンクから編集できます。初回は `data/ai_prompt.md` が作成され、
`# 英語に翻訳`、`# 要約` のサンプルと、`# USER_PROMPT1`、`# USER_PROMPT2` の雛形が含まれます。
（すでに `ai_prompt.md` がある場合は、内容は書き換えません。）

ひな形は次の形式で記述します。

```text
# ひな形名
### 指示:
ここにAIへの指示を書きます。
### 入力:
__TEXT__

-----
```

`# ` で始まる行がひな形名になり、AIパネルにボタンとして表示されます（ボタンには名前だけが表示され、本文は表示されません）。
ひな形の区切りには `-----` を使います。

利用できる置換文字列は次の通りです。

- `__TEXT__`: 編集中の本文全体に置き換わります。
- `__TEXT_SELECTED__`: 編集画面で選択している範囲に置き換わります（選択がないときは本文全体）。

結果が `ng`、`ok`、`desc` を持つJSON配列の場合は、文書校正と同じように置換候補として表示します。
それ以外の結果はテキストとして表示され、「挿入」「Copy」ができます。

```json
[
  {
    "ng": "修正前の文章",
    "ok": "修正後の文章",
    "desc": "修正理由"
  }
]
```

## 標準プロンプトのカスタマイズ

標準の5機能のプロンプトは、次のファイルにあります。

```text
kona3engine/template/prompt/{ja,en}/{proofread,rephrase,append,quality,improve}.md
```

画面からは編集できません。変更したい場合は、これらのファイルを直接編集します。
UI言語に対応するディレクトリが使われ、対応言語がない場合は `en`、次に `ja` を使います。
ファイルの形式や置換変数の詳細は `kona3engine/template/prompt/README.md` を参照してください。

## AIヘルプリンク

AIパネルの「？」リンクは、AI機能のヘルプページを新しいウィンドウで開きます。
リンク先は次のページです。

```text
https://kujirahand.com/konawiki3/index.php?AI
```

## トラブルシューティング

AI支援ボタンが表示されない場合は、設定画面のAIセクションでプロバイダーとAPIキーを確認してください。
OpenAIのAPIキーが未設定でも、OpenRouterのAPIキーが設定されていればAI機能は表示されます。

「AI API Key is not set.」と表示される場合は、選択したプロバイダーのAPIキーが設定されていません。
環境変数を使う場合でも、設定欄には `@ENV:...` を指定してください。

「言い換える範囲を選択してください」と表示される場合は、言い換えたい文章を選択してからボタンを押してください。

「全部適用」で「見つかりません」と表示された候補は、AIが返した修正前の文字列が本文と一致しなかったものです
（全角・半角の違いや、改行をまたぐ指摘など）。「探す」で確認するか、手動で修正してください。

応答に時間がかかる長い文章では、タイムアウトすることがあります。その場合は、文章を分けて実行してください。
本文が大きすぎる場合は `Text is too large.` と表示されます。

ユーザーひな形の結果が期待した形式で表示されない場合は、ひな形の指示を確認してください。
置換候補として表示したい場合は、`ng`、`ok`、`desc` を持つJSON配列を返すようAIに指示します。
「AI template not found: USER_PROMPT1」と表示される場合は、`data/ai_prompt.md` に該当の `# USER_PROMPT1` がありません。
