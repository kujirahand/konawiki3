# ページ一覧 (ツリービュー) の仕様 (#314)

KonaWiki3 には、Wiki 内の全ページをフォルダ階層のツリーで表示する
「ページ一覧」ビューがある。Windows の Explorer のようにフォルダを
開閉しながらページを探し、タップ (クリック) でそのページを開ける。

## 有効化

管理画面 (設定) のオプションにある **「ページ一覧の表示を許可する」
(`show_page_list`)** を `true` にすると有効になる。既定は `false`。

- 有効なときだけ、ハンバーガーメニュー (およびフッターメニュー) に
  「📚 ページ一覧」が表示される。
- 無効なときはメニューに表示されず、一覧の URL
  (`index.php?ページ名&pagelist`) へ直接アクセスしてもエラーになる。

## 挙動

- `data/` 以下の `.txt` / `.md` ページを再帰的に列挙し、
  パス区切り (`/`) でフォルダ階層のツリーにする。
  同名の `.txt` と `.md` は1件にまとめる。
- システムページ (`MenuBar` / `GlobalBar` / `SideBar`) と
  ドットで始まるパス (`.meta` など) は表示しない
  (`#ls` プラグインの既定の挙動に合わせる)。
- フォルダ名自体がページとして存在する場合は、フォルダ名の横に
  そのページへのリンク (🔗) が付く。フォルダ名のタップは開閉専用で、
  開閉とページ遷移が競合しないようにしている。
- ビューには「すべて展開 / すべて折りたたむ」ボタンと、
  ページ名による絞り込み入力がある。
- 非公開 Wiki (`wiki_private`) では、通常のページ表示と同様に
  ログインしていないと一覧を表示できない。
- 静的HTML出力モードでは一覧は生成されない (動的ページ専用)。
  アクションへの直接アクセスも表示を拒否する。
- ページの列挙 (`kona3getAllPages()`) は同一リクエスト内では再走査せず、結果をメモ化する。
