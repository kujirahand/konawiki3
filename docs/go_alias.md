# go.php のエイリアス機能

`go.php?{ページ名}` は、指定されたページの表示画面(`index.php?{ページ名}&show`)へリダイレクトする短縮リンクです。

さらに `data/alias.json` を用意すると、エイリアス名から実際のWiki名へリダイレクトできます。

## alias.json の書式

`data/alias.json` に、`エイリアス名` と `実際のWiki名` の対応を記述します。

```json
{
  "エイリアス名1": "実際のWiki名1",
  "エイリアス名2": "実際のWiki名2",
  "エイリアス名3": "実際のWiki名3"
}
```

## 使い方

上記のように `alias.json` を用意すると、以下のようにアクセスできます。

- `go.php?エイリアス名1` → `index.php?実際のWiki名1&show` へリダイレクト

エイリアスに登録されていない名前を指定した場合は、これまで通りその名前のページへリダイレクトします。

## 補足

- `alias.json` が存在しない場合や、JSONとして壊れている場合は、エイリアスなしとして動作します。
- キーまたは値が文字列でない項目、空文字の項目は無視されます。前後の空白は取り除かれます。
- エイリアスの参照先がさらにエイリアスの場合は、最大10段まで辿ります。循環している場合は途中で打ち切ります。
