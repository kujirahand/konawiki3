# show アクションのエイリアス機能 (alias-show.json)

`data/alias-show.json` を用意すると、ページ表示(`show` アクション)のとき、常にページ名をエイリアス変換します。
ファイル形式と変換ルールは [go.php のエイリアス機能](go_alias.md) の `data/alias.json` と全く同じです(`@re-rule` による正規表現ルールも使えます)。

## 書式

```json
{
  "@re-rule": [
    ["/^user(\\d+)$/", "User/$1"],
    ["pattern2", "replace2"]
  ],
  "simple1": "simple-replace1",
  "simple2": "simple-replace2"
}
```

- `@re-rule`: `[パターン, 置換文字列]` の配列。パターンは区切り文字付きのPHP正規表現で、置換文字列では `$1` などが使えます。上から順に試し、最初にマッチしたルールを適用します。
- それ以外のキー: エイリアス名 → 実際のWiki名 の単純な対応。

## 動作

- `index.php?エイリアス名&show` にアクセスすると、変換後のページの表示画面へリダイレクトします。
- 単純な対応(完全一致)が `@re-rule` より優先されます。
- 変換されなければ、通常どおりそのページを表示します。
- 変換結果がさらに変換される場合は最大5段まで辿ります。
- 変換後の名前がさらに別の名前へ変換されてしまう場合(循環・段数超過)は、リダイレクトの無限ループを避けるためリダイレクトしません。
- `alias-show.json` が存在しない場合や、JSONとして壊れている場合は、何もしません。
